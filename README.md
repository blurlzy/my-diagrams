# My Diagrams

A personal collection of technical diagrams and visual notes about cloud, AI,
and data platforms, with a focus on Microsoft Azure and Microsoft Fabric.

All diagrams are created in [Excalidraw](https://excalidraw.com/) and stored in
the editable `.excalidraw` format.

## Diagram catalog

### AI

- [AI harness](ai/ai-harness.excalidraw) - Components and interactions in an AI harness.
- [AI Search flow](ai/ai-search-flow.excalidraw) - A high-level AI Search workflow.
- [Load PDFs into AI Search](ai/load-pdfs-ai-search.excalidraw) - A flow for ingesting PDF content into AI Search.

### Microsoft Fabric

- [Data governance 1](fabric/data-governance_1.excalidraw) - Data governance concepts and flow.
- [Data governance 2](fabric/data-governance_2.excalidraw) - Data governance in Fabric.

## View and edit

### Excalidraw in the browser

1. Open [Excalidraw](https://excalidraw.com/).
2. Select **Open** from the main menu.
3. Choose an `.excalidraw` file from this repository.

### Visual Studio Code

Install the [Excalidraw extension for VS Code](https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor),
then open any `.excalidraw` file directly in the editor.
